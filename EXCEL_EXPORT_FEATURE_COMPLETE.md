## 📋 WHAT GETS EXPORTED

### **Sheet 1: Customer Enquiries**
```
Contains: All customer contact form submissions
Fields:
  • ID (unique identifier)
  • Name (customer name)
  • Email (contact email)
  • Phone (phone number)
  • Message (enquiry content)
  • Service Interest (what they're interested in)
  • Status (new/replied/closed)
  • Created At (submission date)
  • Updated At (last update)
```

### **Sheet 2: Customer Orders**
```
Contains: All customer orders
Fields:
  • Order ID (order number)
  • Customer Email (buyer's email)
  • Customer Name (buyer's name)
  • Service (service ordered)
  • Status (pending/editing/completed/etc)
  • Price Estimate (quoted price)
  • Admin Notes (internal notes)
  • Created At (order date)
```

### **Sheet 3: Sign-In Logs**
```
Contains: All customer login/logout activity
Fields:
  • Email (login email)
  • Name (customer name)
  • Phone (phone number)
  • Device Type (mobile/tablet/desktop)
  • Sign In Time (login timestamp)
  • Sign Out Time (logout timestamp)
  • Session Duration (minutes logged in)
  • Created At (record date)
```
