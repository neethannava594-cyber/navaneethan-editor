## 🚀 HOW TO USE

### View Website
```bash
1. Open: https://navaneethan-editor.vercel.app
2. Browse all pages
3. Test contact form
4. Check mobile responsiveness
```

### Make Changes
```bash
1. Edit code locally
2. Test: npm run dev
3. Commit: git add . && git commit -m "message"
4. Push: git push origin master
5. Vercel auto-deploys (30-60 seconds)
```

### Monitor Enquiries
```bash
1. Go to: https://supabase.com/dashboard
2. View: enquiries table
3. See all customer submissions
4. Respond to customers
```

### Update Content
```bash
- Edit data.ts         (Portfolio, services)
- Edit profileData.ts  (About page)
- Edit pages.tsx       (Page descriptions)
```
