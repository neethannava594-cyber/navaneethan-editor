## 💻 API FUNCTIONS

### **apiSaveSignInLog(userId, email, name?, phone?)**
- Saves login event automatically
- Called on successful authentication
- Records all user data and metadata

### **apiSaveSignOutLog(userId)**
- Saves logout event and calculates duration
- Called before sign out
- Updates session information

### **apiGetMySignInLogs()**
- Retrieves user's own sign-in history
- Allows self-service log viewing

### **apiGetAllSignInLogs()**
- Retrieves all users' logs (admin only)
- Controlled by Row-Level Security

### **getDeviceType()**
- Auto-detects device type
- Returns: "mobile", "tablet", or "desktop"
- Used in sign-in logging
