# 🔍 WHERE IS "NEW QUERY" IN SUPABASE?

## Step-by-Step to Find It

### Step 1: Open Supabase
```
Go to: https://app.supabase.com
```

### Step 2: Select Your Project
```
Click on your project (e.g., "navaneethan-editor")
You should see the dashboard
```

### Step 3: Find "SQL Editor"
```
Left Sidebar Menu:
├─ Home
├─ Tables
├─ Auth
├─ Storage
├─ SQL Editor  ← CLICK HERE
├─ Realtime
└─ ...
```

**Click: SQL Editor** (left sidebar)

## The Two Ways to Create New Query

### ✅ Way 1: Click "+ New Query" Button (TOP)
```
In the main editor area, at the top left
You'll see: [+ New Query] button
Click it!
```

### ✅ Way 2: Click in Left Sidebar
```
In the left sidebar under "SQL Editor"
You'll see: [+ New Query] link
Click it!
```

## If You Can't Find It:

1. **Are you logged in?** → Check top right has your user icon
2. **Is project selected?** → Check top shows your project name
3. **Refresh page?** → Press F5, try again
4. **Check browser?** → Works best in Chrome, Firefox, Safari
5. **Still stuck?** → Check Supabase docs: https://supabase.com/docs/guides/api/sql-queries
