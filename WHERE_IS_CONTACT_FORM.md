## How to Fill the Form - Step by Step

### **Step 1: Fill "Name" Field**

Click on the box under "Name *" and type:
```
TestUser123
```

```
┌───────────────────────┐
│ Name *                │
│ ┌─────────────────┐  │
│ │ TestUser123   ▌ │  │ ← Type your name here
│ └─────────────────┘  │
└───────────────────────┘
```

---

### **Step 2: Fill "Email" Field**

Click on the box under "Email *" and type:
```
test@example.com
```

```
┌───────────────────────┐
│ Email *               │
│ ┌─────────────────┐  │
│ │ test@exam...  ▌ │  │ ← Type your email here
│ └─────────────────┘  │
└───────────────────────┘
```

---

### **Step 3: Fill "Phone" Field (Optional)**

Click on the box under "Phone (Optional)" and type:
```
1234567890
```

```
┌───────────────────────────────┐
│ Phone (Optional)              │
│ ┌─────────────────────────┐  │
│ │ 1234567890            ▌ │  │ ← Or leave blank
│ └─────────────────────────┘  │
└───────────────────────────────┘
```

---

### **Step 4: Pick "Service Interest"**

Click on the dropdown box under "Service Interest" and select one:

```
┌───────────────────────────────┐
│ Service Interest              │
│ ┌─────────────────────────┐  │
│ │ Pick one             ▼ │  │ ← Click here
│ └─────────────────────────┘  │
```

When you click it, options appear:
```
├─ reel
├─ vertical
├─ slide
└─ general
```

Pick ANY one, for example: **"reel"**

---

### **Step 5: Fill "Message" Field**

Click on the big text box under "Message *" and type:
```
This is a test message to check if the form is working
```

```
┌────────────────────────────┐
│ Message *                  │
│ ┌──────────────────────┐  │
│ │ This is a test...  ▌ │  │ ← Type your message here
│ │ (can be multiple    │  │
│ │  lines)             │  │
│ └──────────────────────┘  │
└────────────────────────────┘
```

---

### **Step 6: Click Submit Button**

At the bottom of the form, click the blue button:

```
┌─────────────────────┐
│   Submit            │  ← CLICK THIS
└─────────────────────┘
```

---

## What Happens After Submit

### **✅ SUCCESS (Best Case)**

You'll see a **GREEN** message:
```
┌─────────────────────────────────────┐
│ ✅ Thank you for your enquiry!      │
│ I will get back to you within 24    │
│ hours.                              │
└─────────────────────────────────────┘
```

The form will also empty (blank) showing your data was sent!

### **❌ ERROR (Problem Case)**

You'll see a **RED** message with an error. For example:
```
┌─────────────────────────────────────┐
│ ❌ Error message here               │
└─────────────────────────────────────┘
```

---

## After You See Success Message

1. **Go to Supabase:**
   - https://app.supabase.com

2. **Click your project**

3. **Click "Editor"** on left side

4. **Click "enquiries" table**

5. **You should see your test entry!** ✅
