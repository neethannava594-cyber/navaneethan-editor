# ⚡ CUSTOMER DATA EXCEL EXPORT - QUICK START

## 🚀 Get Started in 2 Minutes

### **Step 1: Login** (30 seconds)
```
1. Go to: https://navaneethan-editor.vercel.app
2. Click Login
3. Enter your credentials
4. Click Sign In
```

### **Step 2: Go to Export Page** (10 seconds)
```
URL: https://navaneethan-editor.vercel.app/#/admin/export
Or: Click Dashboard → Export
```

### **Step 3: Prepare Data** (30 seconds)
```
Click: "📊 Prepare Data" button
Wait: Data fetches from database
See: Summary of records
```

### **Step 4: Download Excel** (30 seconds)
```
Click: "⬇️ Download Excel" button
Wait: File downloads
Open: customer-data-DATE.xlsx
```

---

## 📊 What You Get

### **3 Excel Tabs:**
1. **Customer Enquiries** - Contact form submissions
2. **Customer Orders** - All orders placed
3. **Sign-In Logs** - User login activity
