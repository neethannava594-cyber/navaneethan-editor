## 🎯 API FUNCTIONS

**apiSaveSignInLog(userId, email, name, phone)**
- Called automatically on login
- Saves login data

**apiSaveSignOutLog(userId)**
- Called automatically on logout
- Saves logout time + duration

**apiGetMySignInLogs()**
- Retrieve user's own logs

**apiGetAllSignInLogs()**
- Retrieve all logs (admin)

**getDeviceType()**
- Detect device type
